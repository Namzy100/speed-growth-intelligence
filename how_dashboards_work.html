1

2

Every record is quality-checked and rated, so nothing fake, broken or half-empty gets through.

3

Where the data comes from

Real sources, one shared home

🎥

Creator platforms

YouTube, TikTok, X. Public creator profiles — how many followers they have, how engaged those followers really are, and what they post about.

📈

Marketing platforms

Adjust — how many people install the app and how many stay. Meta — what we spend on ads and what those ads bring back.

🗄️

The database

One central store. Everything above lands here, so every dashboard reads from the same single, trusted source — never a private copy.

Think of it as one filing cabinet everyone shares. If a number is right in the cabinet, it's right on every dashboard.

Before anything becomes a dashboard

Nothing gets in unchecked

🛡️

The credibility check

Before a creator is saved, it's checked for real, sensible numbers. Anything fake, empty or broken is refused and logged — never quietly saved. A wrong number is more dangerous than a missing one, so we'd rather leave a gap than guess.

⭐

The score, 0 to 100

Each creator gets a score from four honest signals: how well they fit our audience, how engaged their followers really are, how big their reach is, and their real sponsorship history. If a signal can't be measured honestly, it's left out — not faked to fill the box.

This is why the scores are worth trusting: they're built only from signal we can actually stand behind.

How data becomes a webpage

The page builds itself

A "builder" reads the database and writes the finished dashboard — every card, every table, every colour. Nobody edits a dashboard by hand, ever.

🔗

Always in sync

The page is generated from the live data, so it can't quietly drift away from what's true.

🧯

No human slips

No typos, no broken formatting, no "someone forgot to update tab 3."

🔄

Repeatable

Change the data, run the builder again, the page updates itself — identically, every time.

How it stays current

Every morning, on its own

A scheduled job runs in the cloud each morning — not on anyone's laptop, so it works even when every computer in the office is switched off. It refreshes the data, rebuilds the pages and publishes them live.

And if something goes wrong, it fails loudly. It raises a visible failure rather than quietly publishing stale or half-finished numbers. That's deliberate — a blank or flagged dashboard is honest; a confident-looking wrong one is not.

What handover means for you

🚫You won't touch
  • Any code
  • The database directly
  • Rebuilding pages by hand
  • Running anything technical
🛠️Ask an engineer for
  • A new data source
  • A change to how scoring works
  • A daily run that failed
  • A brand-new dashboard

Short version: reading and judging is yours; building and fixing is the engineer's.
